# 声学特征提取 / Feature extraction

模块 `native/src/features.cpp` 由生产Analyzer和主机实验共同调用；Android回调不计算特征，工作线程计算。特征值以ABI v2追加字段传给高级诊断；原C ABI v1结果结构大小不变。没有独立的“只为测试而正确”的生产替代算法。

| 特征 | 数学定义 / 单位 | 物理意义与实际用途 | 条件与局限 |
|---|---|---|---|
| DC均值 μ | Σx/N，FS | 去除直流后进行周期和能量分析 | 逐窗去均值不是连续高通；低频漂移仍影响分析 |
| 短时RMS / 能量 | E=Σ(x−μ)²；RMS=√(E/N)；20log₁₀RMS dBFS | 静音数值地板、信号电平和噪声底输入 | dBFS是数字幅度，不是dB SPL；未作声压校准；不以−60dBFS拒绝所有弱音 |
| 削波比例 | count(|x|≥0.999)/N | >2%标记削波，不输出有效音高 | 只能检测输入达到数值极限；硬件在更早级削波未必可见 |
| 噪声底F | 非周期/不合格窗电平的非对称EMA，下降0.2s/上升3s | 显示背景估计与L−F电平余量 | 未观察背景则未知；语音可污染；不是经分离估计的真实SNR；不作为硬门控 |
| YIN差分d(τ) | 固定W窗的Σ(z[j]−z[j+τ])² | 评估重复周期，弱基频仍可由共同周期恢复 | 多源、非谐性、强瞬态可能没有唯一周期 |
| CMNDF d′(τ) | τd(τ)/Σ(j=1..τ)d(j)，d′(0)=1 | 归一化减少大滞后偏好，局部谷生成候选 | 阈值是工程假设；不是概率；高噪声的偶然谷会误导 |
| 周期评分q | clamp(1−d′,0,1) | ≥0.88才合格；≥0.97允许较快2帧确认 | 高分也可能是错误整数周期，不能单独证明正确 |
| Hann强谱峰 | w[n]=0.5−0.5cos(2πn/(N−1))；局部峰log幅插值 | 谐波门控，诊断真实频谱 | 有限窗有泄漏/分辨率限制；18%幅门槛可漏弱分音；FFT峰不是F0 |
| 谐波一致性h | 一致强峰的Σ|X|² / 全部保留强峰Σ|X|² | ≥0.85支持YIN候选；排除部分非整数关系双音 | 整数谐波关系的多个音源仍可通过；不能声称已实现复音分离 |
| 功率谱重心 | Σ fₖ|Xₖ|² / Σ|Xₖ|²，k=1..min(8kHz,Nyquist) | 展示能量分布；用于课程分析和设备/噪声诊断 | 不用于F0选择或调准判断；截断频段影响值，非感知响度模型 |
| 音高变化率 | 1200(log₂fₖ−log₂fₖ₋₁)/dt，cents/s | 诊断时间变化，分离抖动和真实滑音 | 无效后首次不可作连续真值，跨声源不可解释为乐器连续运动 |
| 连续帧一致性 | 候选计数/所需计数；跟踪态exp(−|innovation|/80) | 状态机解释、稳定性诊断；连续同向>12c用于调快平滑 | 这是归一化相容度，不是正确概率，也不是独立声学证据 |

并非所有特征都参与融合：谱重心、噪声底、电平余量用于可观察性而非“堆特征”提高虚构准确率。实际候选融合仅使用周期性、谐波一致性、周期长度惩罚与显式门控；时序模块使用候选有效性、周期评分、对数音高残差、方向一致性和时间间隔。

当前ABI3波形传输至多512个真实PCM显示样本，显示专用抗混叠抽取/时间轴见[波形显示](waveform-display.md)。旧ABI1/2兼容128组min/max包络，不能将其作为PCM序列。频谱显示前512个真实FFT bin，横轴k fs/Nfft，纵轴20log₁₀(2|X|/Σw) dBFS/bin（DC不乘2），下限−120dBFS。零填充只细化采样网格，不增加实际频率分辨率。谱重心的计算频段与界面前512bin显示上限不完全相同，不能从截断界面图直接重算全特征。

数据流和YIN/pYIN引用见[audio-signal-processing.md](audio-signal-processing.md)。项目没有把上述已有定义当作原创；新增内容是可审计的工程组合、边界策略、实时状态管理和同数据对照实验。


## 钢琴模式

ET钢琴独立使用180ms/20ms的PianoAnalyzer；机械校准独立使用750ms/100ms的PartialAnalyzer，均在同一worker分析真实采样率PCM，不改通用跟踪参数。详见[piano-foundation.md](piano-foundation.md)、[piano-calibration.md](piano-calibration.md)及[验证结果](validation.md)。
