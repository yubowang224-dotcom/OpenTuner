- 稳态抖动：稳态有声区输出相对恒定载频的SD（真颤音不是噪声抖动，不混统计）。阶跃同时记录进入±10c后连续3帧的第一帧和第三帧确认时刻；滑音相对窗末瞬时真值，保留窗口/滤波滞后，绝不时间平移对齐以美化误差。
- CPU/耗时：同一PCM分别运行baseline和新生产，记录每帧分析与各tracker额外时间；Windows单独记录进程用户+内核CPU时间/峰值驻留内存。不能把固定平滑的微秒耗时写成整个算法CPU时间。手机端到端延迟/温升/CPU/PSS无设备即未测。
