# 原创拨弦参考音与节拍器音量

这是项目的加法合成工程实现，不是采样吉他音色，也不声称完整物理琴弦模型。无音色下载/第三方素材/新运行依赖；所有源代码沿项目Apache-2.0公开。钢琴参考音保持原正弦（0.15FS峰值、默认gain1），不将吉他音色统一应用于钢琴。

## 吉他拨弦近似

实际输出采样率R，目标频率f0来自当前预设，不用整数延迟线近似定音。单一连续相位φ累加2πf0/R，最多8个整数谐波：

`y(t)=0.65 × g × A(t) × Σ [w_n/W × exp(−(0.35+0.17n)t) × sin(nφ(t))]`

权重[0.8,0.55,0.32,0.20,0.12,0.08,0.05,0.03]，仅保留nf0<0.45R的分音，W为保留权重总和。不同分音衰减使高频较快消退，形成清楚的拨弦起音；没有非谐性、噪声激励或琴体共振，不应叫真实吉他录音。

控制线程预计算衰减乘数exp(−(0.35+0.17n)/R)，回调固定上限8次正弦及标量乘法；无分配、锁、日志、I/O或JNI/Dart。所有振荡器/包络归回调独占。A(t)起音10ms线性；3秒自动释放，停止时从当前包络值开始30ms raised-cosine收音，分音与相位连续。g∈[0,1]，默认0.8，理论绝对峰值≤0.65g，保留至少约3.7dB数字余量；真实模拟输出/系统音效是否削波不由数字上限保证。

Dart ReferenceTimbre.guitar/gain→toneStart(hz,voice=1,gain)→Kotlin校验→JNI nativeToneStart(session,hz,voice,gain)→ReferenceEngine/ToneSynth。默认voice0/gain1保持钢琴正弦。吉他滑杆调整停止旧音，用户再次播放，避免运行中突然改变不可变振荡器参数。参考音先停止并释放采集；结束后250ms界面冷却，仍需用户手动开始，不把手机自发声显示为外部琴弦调准。导航/后台/焦点/路由释放沿原owner规则。

## 实测起音增强与自然衰减的权衡

105组生产合成器条件=5采样率（8/44.1/48/96/192kHz）×7频率（D2/E2/A2/D3/F#3/B3/E4）×gain0.25/0.8/1；另测0静音、非法gain、重复释放、1/7/40/250ms早停及3秒自动释放。实际峰值最大0.419821FS，105条件中生产Analyzer在1785观察帧里接受1680（每条件首帧候选拒检也在分母），最大条件P95误差0.70225c；这不是手机参考音声学精度承诺。全部接受帧频率误差须<5c，接受率须≥90%。谐波投影验证非整数分音比基频低，所有停止包络首样本与不中断对应样本一致到1e-7。

下表是默认gain0.8相对旧0.15FS持续正弦的实际分段RMS变化（dB），全部四个测试频率均列出：

| Hz | 0–0.25s | 0.25–1s | 1–3s | 0–3.03s |
|---|---:|---:|---:|---:|
| 73.416 | +3.923 | +1.391 | −4.790 | −1.159 |
| 82.407 | +3.924 | +1.407 | −4.790 | −1.156 |
| 110 | +3.925 | +1.403 | −4.787 | −1.157 |
| 329.628 | +3.915 | +1.402 | −4.786 | −1.159 |

因此仅能说“起音增强、谐波更丰富，后段自然衰减”，不能说全程RMS都更大。CSV还记录gain1和≥300Hz谐波指标：各整数分音的Hann归一化投影幅值平方之和/2，属于合成分音能量近似，不是完整带通积分、更不是手机传递函数/SPL/心理响度。低音的可听分音增加有工程依据，但实际扬声器听感仍待检查。

## 节拍器

默认数字点击幅度提高2倍（+6.0206dB），强/次强/普通/细分理论上限0.44/0.36/0.28/0.14FS。仍为12ms点击、1ms起音、原余弦衰减、5ms停止、20–300四分音符BPM及6/8的3+3。没有叠加点击，无硬限幅顶满。

App 0–100%音量独立于系统媒体音量，默认100%，会话内有效、不持久化。Dart MetroConfig.gain→Kotlin→JNI start/update→ReferenceEngine锁自由32位requestedGain→回调MetronomeSynth.setGain。仅音量变化不会queue拍速配置，因此不会重置beat/ticks；每样本最大步进1/(R/200)，全量程约5ms，避免音量跳变。快照ABI2为17字段，末尾gain是回调已收到的目标百分数（非瞬时包络增益），最长仍有5ms slew；兼容16字段ABI1默认100。gain随MetroMailbox同一序列发布以保持并发一致性。

320组合实际PCM与十分钟同调度器时钟测试保留。6000点击事件逐样本与独立旧公式×2比较，峰值最大0.430377FS，实测RMS增益6.020599912–6.020599931dB；强弱比例保持。另4采样率×0/25/50/100%检查输出线性比例/静音与时钟相同，测试播放中0→快速10/90/50及停止、非法范围、并发gain字段一致性。物理响度、蓝牙/扬声器音色与焦点/路由系统执行不是host证据。

## 复现

```powershell
. ./tools/activate.ps1
cmake -S native -B build/m1-dsp
cmake --build build/m1-dsp --config Release
ctest --test-dir build/m1-dsp -C Release -V
python tools/report_guitar_m1.py
```

逐帧/逐条件/各段电平CSV与原创对照WAV在build/m1-dsp/{guitar-results,voice-results,metronome-results}，汇总和图在artifacts/m1-guitar/results。WAV为4秒（含收音后静音），不加入Git二进制历史。测试工具会按固定协议重新生成，CI上传CSV；远端CI尚未运行。

绘图开发工具使用既有tools/requirements-evaluation.txt固定numpy/matplotlib版本，不随APK分发。报告脚本用提交的LF源码哈希核对冻结输入核心，无Git历史也可生成图表；旧逐帧CSV比较为可选，缺失时明确写not compared，不伪造0差异。可用--comparison指定此前evaluation/frames.csv。本次已实际比较57330行，0个非耗时差异；另在无Git/旧CSV的最小源码副本实跑报告成功并标比较未执行。
