# 阶段2预先固定的测试协议

本协议在首次运行生产DSP测试之前建立。失败保留，修复算法可以重跑，但不删除不利场景或改变统计区间来宣称原目标通过。

- 生产候选范围50–2000 Hz，不含钢琴A0–C8承诺。采样率44100/48000，窗80 ms，步20 ms；不重采样。输入float满量程±1。
- 主静态集：50、55、65.406、82.407、110、146.832、220、337.13、440、659.255、880、997.31、1000、1567.98、1990、2000 Hz；峰幅0.03/0.3/0.8，各1.5秒。全部从第0样本输入；误差、覆盖、抖动固定统计0.3–1.5秒的**所有**输出帧，拒检计入分母。首次检测从第0样本计时。
- 主目标：有效帧绝对音分误差median≤2、P95≤5，覆盖≥99%。原阶段0主音域65–1000 Hz P95≤2及tracked抖动≤1cent目标另列，不因新目标而删除。
- 谐波：82.407/220/440 Hz，弱基频[0.05,0.6,0.3]、缺失基频[0,0.6,0.3,0.2]，归一化峰值≤0.8；同一统计区间，单列结果。
- 干扰：固定mt19937种子20261018，白噪声、静音、脉冲、DC、440Hz+0.35DC、削波440Hz、SNR40/20/10/0dB、220+337.13Hz非谐双音。拒检与高评分(≥0.9)误报均记录；双音无唯一真值。
- 动态：220→440 Hz在0.6秒切换；220→330Hz连续滑音；幅度衰减；0.6秒消失、1.0秒重现。新音进入±10c并连续3帧才记切换成功；失效时间从停声到首个无效帧，另记录稳定清除。原150ms阶跃目标保留。响应只含观测窗/跟踪，不含手机硬件或Flutter。
- 输出每帧CSV及汇总JSON/Markdown：raw/tracked、有效性、score、RMS/clip、真值、时间和DSP耗时。计时Release；报告CPU/OS/编译器，不当作手机端到端延迟或整机CPU/内存。
- 环形队列满时producer丢新数据，consumer可以安全清空其拥有的积压；总量有界，记录丢样数，遇数据断点重置窗和跟踪。
- Flutter覆盖会话失效、权限结果、停止后旧帧、重复开始/停止、后台/离页、真实数据页面与桥接字段校验。模拟权限不等于Android系统弹窗测试。
- 无连接设备时，所有权限/设备路由/麦克风隐私/端到端/温升/手机CPU-PSS/16KB设备运行项目均为待验证。
