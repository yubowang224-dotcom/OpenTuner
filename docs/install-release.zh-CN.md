# 安装OpenTuner

当前版本0.7.0-beta.2，versionCode5001，Android7/API24及以上。安装包位于[GitHub Releases](https://github.com/yubowang224-dotcom/OpenTuner/releases)的Assets区域；尚无对应Release时表示安装包尚未发布。

## 选择安装包

- 普通64位Android手机推荐arm64-v8a。
- 不确定架构可选universal通用APK。
- armeabi-v7a供对应32位设备；x86_64供对应架构设备/模拟器。

核对文件SHA256与随附SHA256SUMS.txt；正式证书SHA256应为`ae27b3e61d3d21419b6a45236bc9c56cbddcf05044a2311f56f4627d2eaf6892`。

## 已有旧测试版

**先不要卸载。** Debug和正式证书不同，不能直接覆盖。当前无档案导出/导入入口，Android backup关闭，卸载会丢数据。[先读迁移说明](debug-to-release-migration.zh-CN.md)。

## 首次安装

将合适APK复制至手机，在文件管理器点击安装，只给该来源必要的安装许可。成功后设置页显示0.7.0 Beta2，系统包版本0.7.0-beta.2/code5001。

遇到签名冲突先停止，不直接卸载；遇到架构不符选正确ABI或通用包；文件损坏重新核哈希。不要关闭系统保护强行安装。签名检查通过不保证所有手机均已运行验证。

## 无乐器检查

1. 进入试测音，主动开始后授予麦克风权限；哼唱、停声和改变距离，观察可靠性及真实波形/频谱。无可靠单音时应明确无效。
2. 在电脑生成并播放已知频率WAV，手机通过空气拾音。`python tools/generate_test_tones.py`生成220/440/880Hz、滑音、阶跃和带静音间隔测试音；产物位于脚本指定artifacts目录。电脑空气播放是功能检查，不是校准声学认证；哼唱没有精度真值。
3. 测试拒绝/永久拒绝权限、切页/后台、返回后手动恢复、参考音与采集互斥，检查无红屏/溢出。
4. 节拍器测试开始/暂停/恢复/停止、音量0和路由/后台停止；暂停保持拍位，停止复位。
5. 检查两语言、主题、极简与字体缩放。按[设备模板](device-test-m3-template.md)记录版本、型号、实际采样率、声源、现象和未测项。

机械校准仍Experimental，默认支持A1–A6；合成结果不替代实琴验证。手机端到端延迟需同步测量，不能用电脑DSP耗时冒充。
