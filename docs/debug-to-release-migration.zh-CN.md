# 从Debug测试版迁移到正式签名版

正式版包名仍为`org.opentune.tuner`，使用与旧Debug不同的专用证书。**Android不允许异签名直接覆盖升级。先不要卸载或清除数据。**

当前没有用户档案导出/导入入口，Android自动备份也已关闭。卸载/清数据会丢失主题、A4和钢琴档案。复制APK只保存程序，不是数据备份；当前不承诺自动或无损迁移。

## 已安装旧Debug

1. 保留旧应用、原签名APK和本地数据。需要保留档案时，先停止安装流程。
2. 先与维护者确认可用的数据导出和恢复方案；尚未实现、验证的方案不能当作已有功能。
3. 任何备份都应先核实可读、包含所需数据并有实际可行的恢复路径；没有导入入口时，单份备份不代表可直接恢复。
4. 若自行确认完全不需要旧数据，可决定卸载后首次安装正式版；否则不要为了消除签名冲突先卸载。

不要将可能包含姓名的原始档案贴到公开Issue或Release附件，不通过绕过签名检查的方式强装。

## 正式版后续更新

三ABI和通用APK使用同一正式证书与统一versionCode5001，后续单调递增。换架构包也需要设备兼容、同证书和合适版本。更新一致性依赖原密钥，不能用新建同名证书替代。实际覆盖安装及档案保留仍需手机验证。

新用户没有同包名旧应用时，可按[安装指南](install-release.zh-CN.md)选择已核对哈希/证书的APK。
