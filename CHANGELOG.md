# Changelog

## 0.7.0-beta.2 — 2026-10-19

- Dedicated release certificate, unified versionCode5001 across three ABI APKs and universal APK; optimized AOT packaging.
- Repository URL in the acknowledgements page, installation and signing/migration documentation.
- Flutter analysis and13 targeted tests; independently extracted source passed7 smoke tests and an unsigned arm64 AOT build without the official key. Phone and real-piano validation remain pending.

## 0.6.1 — 2026-10-19

- Separate sample-domain metronome pause/resume and stop/reset, preserving musical phase during pause.
- Fix17-field snapshot parsing, add19-field transport/heartbeat, and ensure muted resume starts at zero.
-208 Flutter checks,12 native groups and final affected regression checks recorded.

## 0.6.0 — 2026-10-19

- Experimental stiff-string partial fitting, quality rejection and guided mechanical-piano calibration.
- Bounded individual targets, schema2 provenance, resampling hints and safe profile loading. Default supportA1–A6, no extrapolation.

-88-key ET piano targets, independent native analyzer, shared persisted A4 and local profiles.
- Fix TextField/ExpansionTile PageStorage type conflict with a distinct typed key.

## 0.4.0 — 2026-10-19

- Seven six-string guitar presets, automatic/manual selection, synthesized pluck references and App gain.
- Accessible bilingual acknowledgements page.

## 0.3.x — 2026-10-18–19
